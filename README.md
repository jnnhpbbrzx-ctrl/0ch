# 0ch Messenger

Тёмный мессенджер: общий чат, личные сообщения, голосовые звонки, шаринг экрана.

## Деплой на Railway

1. Создай **новый** репозиторий на GitHub.
2. Залей **все файлы** из этой папки.
3. Railway → New Project → Deploy from GitHub repo.
4. (Опционально) Variables → `JWT_SECRET` = длинная рандомная строка.
5. Дождись деплоя.

## Что есть

- Регистрация + обязательные правила
- Общий чат `# general` + личные сообщения (клик по нику)
- Аватарки, фото, видео
- Голосовые звонки (WebRTC + TURN TCP 443)
- Трансляция экрана
- Mute / шумодав браузера
- Модерация (удаление сообщений для owner/mod)
- Шифрование сообщений
- Адаптив под телефон

## Локально

```bash
cd backend && npm i && node server.js
cd frontend && npm i && npm run dev
```
